# B 站扫码登录

在系统设置中点击「扫码登录」，使用 B 站 App 扫描二维码并在手机上确认。程序验证账号后保存到本机，无需浏览器扩展或复制 Cookie。

源码入口：`python tray_app.py --login`。已安装桌面程序也可使用 `LiveSupport.exe --login`。

## 实现

- 官方接口申请和轮询二维码，展示等待、待确认、过期及成功状态。
- 官方 spi 下发设备字段；整个扫码流程和后续账号请求使用同一 User-Agent，不生成替代设备标识。
- 确认后保留登录、账号及设备 Cookie 白名单，校验请求头格式及账号匹配；不读取浏览器 Cookie 数据库，不保存任意 Cookie。
- 保存前调用认证接口核对账号；过期、取消、关闭和失败不保存结果。
- Windows 使用当前用户 DPAPI；其他平台要求可用的系统凭据库。旧明文原子迁移，无法保护时拒绝保存。
- 新会话会替换旧会话字段；不会重置认证 UID 的每日预算，也不会自动解除验证或权限异常。

扫码是在本程序建立新的登录会话，不等于已有浏览器配置中的全部 Cookie。若旧安装只保存两项凭证，需要重新扫码才能取得此前未保存的会话字段。

## 验收与边界

离线测试覆盖二维码状态、响应解析、白名单、账号绑定、原子保存及取消。控件测试使用合成数据。真实账号验收应在本机核对认证及任务变化，不把 Cookie、原始请求或账号时间线提交到公开仓库。

见 [ACCOUNT_SAFETY.md](ACCOUNT_SAFETY.md) 与 [LIVE_LIKES.md](LIVE_LIKES.md)。
