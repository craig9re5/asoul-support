# 桌面逻辑与验证

## 与脚本一致的行为

- 自动任务、手动补齐、看播和 CLI 使用共享 AppContext 及业务服务。
- 登录状态来自认证结果，房间查询失败不覆盖已确认的账号状态。
- 设置通过扫码建立新的登录会话；取消、关闭和过期不保存旧异步结果。
- 表格原位更新，保留选择、焦点和滚动；后台 IO 不直接操作 Tk 控件。
- 账号保护暂停显示原因和冷却时间，托盘提供处理入口。普通挂机恢复不能解除保护暂停。
- 凭证内容的语义哈希识别会话变更；重复加密相同会话不无故重启 worker。
- 同步勋章、自启动和凭证存储失败显示明确错误。

## 离线验收

```powershell
python tools/offline_test.py
python tools/desktop_smoke.py
```

离线 runner 使用隔离数据目录，禁止网络请求。真实 Tk 控件检查覆盖主窗口、设置、二维码及取消、添加主播、勋章同步和账号保护状态投影。测试采用合成账号数据，不主动发送真实互动或触发平台限制。

冻结程序需另用隔离目录执行 `--diagnostic`，确认 `ok`、`frozen` 和版本。源码控件检查不能代替冻结程序检查。整合基线没有重新发布 EXE；本机已有安装不会因远端发布清理而自动改变。

第二阶段默认策略与并发限制等待调研。详情见 [ACCOUNT_SAFETY.md](ACCOUNT_SAFETY.md)。
