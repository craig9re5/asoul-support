# 整合后的重构结果

源码基线：2026.09.30.8。上游来源与许可见 [NOTICE.md](../NOTICE.md)。公开历史从整合基线开始，不保存个人实测时间线。

## 分层

| 部分 | 职责 |
| --- | --- |
| scripts 与 cli | 兼容命令入口、参数解析和输出 |
| AppContext | 显式应用作用域、凭证、配置及共享服务 |
| services | 每日任务、弹幕、点赞、看播、视频和动态业务 |
| http、session_headers、safety | 请求、会话匹配、异常保护与共享预算 |
| runtime、secret_store、redaction | 原子存储、系统凭据保护和输出脱敏 |
| desktop | UI、主线程调度、快照投影、进程管理及对话框 |

核心不依赖 GUI 或脚本；桌面不改共享模块变量或 sys.argv。旧常量及兼容函数仍保留，业务规则共用服务。

## 已修正的问题

- API 失败、动态错误码及分页不完整不再误报成功或空数据。
- 点亮与每日任务由服务端状态确认，不按发送成功数推断完成。
- 弹幕有限尝试、跨进程间隔、周期巡检及跨日确认。
- 独立心跳链状态，按单调时钟预算与服务器实际间隔计时。
- 配置在锁内验证并原子合并，避免并发覆盖。
- UI 更新通过主线程队列，关闭窗口丢弃过期结果。
- 扫码会话验证及原子保存；不同账号不混用会话字段。
- 异常暂停与每日预算绑定认证 UID，重新登录保留预算。
- 写请求结果未知时不盲目重放；桌面和 CLI 共用恢复约束。
- Windows DPAPI/系统凭据库、旧明文迁移、注销及脱敏。

## 验证

离线测试、结构检查及真实 Tk 控件测试使用隔离目录，禁止账号网络请求。公开扫描检查文件、历史、提交元数据，并可在本机使用显式指定的凭证做精确值比对。该检查不能证明不存在所有未知格式的敏感信息。

冻结程序、真实账号任务结算与源码测试分别验收。本次公开历史整合不重新发布 EXE，不改变本机已有安装或账号设置。

## 保留的边界

- 跨进程锁、预算及暂停只覆盖同一数据目录；不同机器/目录不能保证共享约束。
- JSONL 日志长期归档策略仍需按运行规模确定。
- 静态结构检查不能证明不存在所有运行时耦合。
- Windows 桌面及系统功能需要 Windows 验收；其他平台主要验证共享核心。
- 第二阶段默认策略、并发限制、账号每日总量与运行时长等待调研。

验证命令见 [RELEASING.md](RELEASING.md)，清理范围见 [PUBLICATION_CLEANUP.md](PUBLICATION_CLEANUP.md)。
